# Node.js Todo App

A beginner-friendly command-line Todo application built using Node.js and JavaScript.

## Features
- Add tasks
- View tasks
- Delete tasks

## Technologies Used
- Node.js
- JavaScript
- Readline module

## How to Run
1. Install Node.js.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Run `node app.js`.

## Purpose
This project was created to practice JavaScript fundamentals, arrays, functions, callbacks, and user input handling.
